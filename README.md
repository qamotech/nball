# 🏀 Ne'ala Hoops #14

A basketball **training + education** app built for Ne'ala, 11 — a beginner learning the game with her dad as coach.

**Live:** https://qamotech.github.io/nball/

## What's inside
- **Home** — today's plan (editable weekly plan), Drill of the Day, streak, quick stats
- **Train** — 18 drills by skill/level with form cues, featured **14 for 14** driveway session, practice timer
- **Log** — practice sessions with makes/attempts, rebounds, assists, minutes and notes
- **Learn** — Basketball IQ lessons, school-through-basketball (math, vocabulary, reading), **Legends: Cheryl & Reggie Miller** stories and best games, flashcards, quizzes
- **Progress** — charts, practice calendar, per-practice averages, badges with celebrations

## Privacy & tech
- Single-file HTML/CSS/JS, **zero dependencies**, dark mode, phone-first
- **No accounts, no posting, no tracking** — all data lives in the device's localStorage only
- Works offline once loaded
